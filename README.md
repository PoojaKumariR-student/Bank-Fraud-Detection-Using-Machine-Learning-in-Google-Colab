# Bank-Fraud-Detection-Using-Machine-Learning-in-Google-Colab
📝 DESCRIPTION

Bank fraud detection is one of the most important applications of Artificial Intelligence in the financial sector. Fraudulent transactions cause major financial losses to banks and customers every year.A Bank Fraud Detection System is an AI system that checks whether a banking transaction is:
✅ Genuine or ❌ Fraudulent

This project uses advanced AI and Machine Learning technologies such as:

• XGBoost for supervised fraud classification

• Autoencoders for anomaly detection

• SHAP (SHapley Additive exPlanations) for model interpretability


-------
📍OBJECTIVES

→ Detect fraudulent banking transactions using AI techniques.

→ Handle highly imbalanced datasets effectively.

→ Improve fraud detection accuracy using XGBoost.

→ Detect anomalies using Autoencoders.

→ Explain model predictions using SHAP.
